# 원본·보강본 비교 결과 — 2026-08-31

팀 공유용 요약. 실제 가맹점명·record_id·주소·연락처와 개별 판정은 제외했다. 원본·상세 결과는 Git 제외 로컬 자료로 보관한다.

## 실험

- 동일한 전체 가맹점 9,354건에 대해 원본 문서와 보강 문서를 비교했다.
- 3,950건에 짧은 참고 표현을 추가했다. 예: 식육→정육, 칼국수→조리음식.
- BGE-M3 dense, max_length=128, batch_size=32, FP16, Top5, 전체 코사인 검색을 사용했다.
- 장소 제외20질의: 품목·자연어 의도15개와 특정 상호명5개.
- 결과200행을 질의-가맹점 기준으로 중복 제거하면125쌍이다.
- 미판정35건 검토 후23건에 잠정 판정을 추가하고12건은 보류했다.
- 원본 데이터·기존 판정·검색 순위는 변경하지 않았다. 모델 학습/파인튜닝은 하지 않았다.

## 지표

품목·의도15질의 기준. **미판정을 불일치로 가정한 잠정 수치**이며 미검증 AI 판정이 포함된다.

|지표|원본|보강본|
|---|---:|---:|
|판정 보유율|88.0%|88.0%|
|Precision@5|78.7%|78.7%|
|Top1|86.7%|80.0%|
|Hit@5|93.3%|93.3%|
|MRR@5|0.900|0.867|

미판정을 모두 일치로 가정하면 P@5는 두 버전 모두90.7%다. 이는 신뢰구간이나 실제 성능의 보장된 범위가 아니다. 미판정 점포가 버전별로 다를 수 있고 AI 라벨 오류는 별도다.

상호명5질의는 양쪽 모두 Top1·Hit@5·MRR@5가1.0이다. 특정 점포 하나를 찾는 질의의 P@5 20%를 실패로 해석하지 않는다.

## 검색 사례 — 상호 익명화

- 생닭: 닭요리점으로 판정된 원본5위 대신 원본 품목에 생닭·계란이 명시된 가게가 등장했다. P@5 80%→100%.
- 주방용품: 보강본 Top5 모두 원본에 관련 품목 근거가 있다. 원본의 두 후보는 미판정이므로 잠정60%→100%를 확정 개선폭으로 주장하지 않는다.
- 화장품: 보강본 상위에 판매 여부가 미확인인 미용 관련 가게·약국 등이 등장했다.
- 아이 옷: 유아복 가게가 추가됐지만 아동화 가게와 음악학원도 등장했다. 정확 일치 수는 두 버전 모두3/5.
- 국거리 고기: 두 버전의 Top5가 동일하고 칼국수집이1위다. 원육 구매와 조리음식 혼동이 해결되지 않았다.

## 판정 기준과 한계

- 2: 질의 의도와 일치. 상호 단서로 제안한2도 외부 확인 사실과 구분한다.
- 1: 일부 관련성은 있지만 정확한 일치는 아님.
- 0: 명시적 불일치 또는 특정 상호 검색에서 다른 대상.
- 빈칸: 정보 부족. 모름을1이나0으로 채우지 않는다.
- 기존 사용자 진술은 보존했다. 보강 문구나 벡터 점수를 정답 근거로 사용하지 않았다.

평가 후보125쌍 중113쌍에 숫자 판정이 있지만,113쌍 모두 검증된 정답이라는 뜻은 아니다. 독립된 제3자 블라인드 평가도 아니다. 이미 관찰한 개발 질의이며 팀 모델 우열 판단에 필요한 공통 신규 질의는 별도다. nDCG·Recall·서비스 응답시간은 이번 결론에 사용하지 않는다.

## 결론

**이번 보강 방식이 원본보다 전반적으로 우수하다는 근거는 부족하다.** 원본을 기본 기준선으로 유지하고 보강본은 비교 실험으로 보관한다. BGE-M3 자체가 부적합하다는 결론은 아니다.

다음은 [회의 합의 사항](meeting_summary.md)에 따라 공통 데이터·질의·판정을 정하고, 근거 있는 판매형태 보강 등을 한 번에 한 요소씩 비교하는 것이다.

## 재현 자료

코드와 최신 비교 노트북은 Git에 포함한다. 원본/보강 CSV, 평가 질의 및 qrels, 실행 결과 ZIP, 상세 판정표는 별도 승인 경로로 전달받아야 한다. Git clone만으로 회사 데이터 기반 실험 전체를 복원할 수는 없다. 모델 revision·환경·입력 hash는 실제 실행 ZIP의 run_manifest.json에 보관되어 있다.
