# BGE-M3 PoC — 회의 요약

2026-08-31 비교 실험 및 추가 판정 검토 후의 팀 공유용 자료. 실제 가맹점 식별 정보는 제외했다.

## 전달할 핵심

> BGE-M3를 고정하고 원본과 짧은 품목 표현 보강본을 비교했다. 일부 품목 검색에는 개선 사례가 있지만 전체 지표 개선 근거는 부족하다. 원본을 기준선으로 유지하고 원육 구매와 음식점 혼동을 다음 개선 대상으로 삼는다. 현재 수치는 AI 지원 잠정 평가이며 팀 모델 우열을 확정한 것은 아니다.

## 완료 / 미완료

완료: 원본 프로파일링, 최소 검색 문서 생성, 보수적 품목 보강, Colab 전체 코사인 비교, 새 후보 판정과 잠정 지표 계산. 기존 Qdrant 원본 검색 노트북은 참고용으로 유지했다.

미완료: 공통 신규 평가 질의·독립 검증된 정답셋, 다른 팀 모델과의 통제 비교, NICE 공식 분류 매핑, 판매형태 추가 사실 확인, 파인튜닝, sparse/hybrid 실험, 통제된 서비스 속도 측정.

평가 범위는 장소 제외, 품목·자연어 의도15질의와 특정 상호명5질의다. 상세 결과와 수치의 한계는 [결과 요약](results_summary.md)을 참조한다.

## 회의에서 결정할 다섯 가지

1. **공통 데이터:** 같은 원본 문서 버전을 동결하고 보강본은 별도 버전으로 관리한다. 각자 전처리가 다르면 모델 단독 성능 비교라고 부르지 않는다.
2. **공통 질의:** 품목·구어체·상호명으로 범위를 맞추고 개발 질의와 신규 평가 질의를 분리한다. 장소 조건은 현재 제외한다.
3. **공통 판정:** 2=일치,1=부분관련,0=불일치,빈칸=미확인. 각 모델의 상위 후보를 합쳐 중복 제거 후 같은 기준으로 판정한다. AI·상호 추론·사용자 진술·외부 확인을 구분한다.
4. **공통 지표:** 품목·의도 Precision@5, 상호명 Top1을 우선하고 Hit@5·MRR@5·판정 보유율을 병기한다. nDCG/Recall은 현재 보류한다.
5. **추가 정보:** 원육 판매/조리음식 구분의 근거 출처를 정하고, NICE 분류 제공 여부와 매핑 책임을 누가 확인할지 결정한다.

모델 revision·데이터/질의/판정 버전·검색 방식·추론 설정도 함께 기록한다. 캐시 포함 전체 임베딩 시간이나 진행률을 서비스 검색 응답시간으로 발표하지 않는다.

## 학습과 현재 실험의 구분

현재는 사전학습 모델의 가중치를 고정하고 텍스트를 벡터화해 검색한다. 문서 보강 후 재임베딩하거나 관련도 라벨을 입력하는 것만으로 가중치가 학습되지는 않는다.

batch_size·max_length·FP16은 이번 추론 설정이다. learning rate·epoch 등의 학습 설정과 구분한다. 파인튜닝은 믿을 만한 질의-문서 학습 관계와 별도 평가 데이터를 확보한 후 검토한다.

## 당장 선택할 방향

원본을 유지하고 이번 보강본은 실험 사례로 제시한다. 공통 평가 기준을 정한 뒤 판매형태 근거 보강이나 다른 검색 방식을 한 번에 한 요소씩 바꿔 비교한다. 문서 품질 비교 이후 같은 벡터로 Qdrant 검색 결과·속도를 별도 확인한다.
